# fix（Phase 12）：Phase 12で見つけた軽微な修正の記録

## 1. 一時停止したまま送出を始め直すと、最初の1回分が送られることがある（T12-4の`bun run check`中）

- 種別：軽微な修正（要件・設計・インターフェース・タスク構成・プランアセットの確定事項は変えない。UI ⇔ Rust のコマンドとイベントは変えず、Rust の内部で送出のスレッドに状態を渡す順を直した）
- 見つけた検証：T12-4の`bun run check`（macOS）で、`audio_engine::tests::pause_and_sections_are_kept_across_stream_restarts`がまれに失敗した（同じテストを単独で10回回すとすべて通過する、時間に左右される失敗）
- 関連タスク：T2-7・T4-6（最小化時の停止）

### 内容

- 原因：`AudioEngine::start_stream`が、送出のスレッドを起こした後に`set_paused`・`set_active_sections`を伝えていた。伝わる前にスレッドが1回分を送ることがあり、テストの「一時停止中は送らない」に当たった。実害は、最小化中にページを再読み込みしたとき1回分だけ解析と送出が走る程度

### 修正

- `src-tauri/src/frame_transport/mod.rs`：一時停止と有効なセクションを決めてからスレッドを起こす`FrameTransport::start_with`を足し、`start`はこれを既定の値で呼ぶ形にした
- `src-tauri/src/audio_engine.rs`：`start_stream`で`start_with`に今の状態を渡す

### 確認

- `cargo test`を5回続けて回し、すべて通過（153件）
- `bun run check`が通る
