# fix：適合判定のテストに、向きを問わない形の確認を足す（W5-2の検証中）

- 種別：軽微な修正（要件・設計・インターフェース・タスク構成・プランアセットの確定事項は変えない。テストだけを足した）
- 見つけた検証：W5-2（適合判定の単体テスト）
- 関連タスク：T5-2（適合判定）

## 内容

W5-2で、規則を一時的に壊してテストが落ちるかを確かめたところ、次の2つだけが検出されなかった。

- 正方形に近い形の判定が、流れる方向に左右されるようになった場合
- 縦長（周波数別の定位）の判定が、流れる方向に左右されるようになった場合

この2つの形は、枠の縦横比だけで決まり、向きを問わない規則（モックの`fitOf`と同じ）。しかし既存のテストは、この2つを方向なし（`null`）でしか試しておらず、向きに依存する不具合を見逃していた。実装は規則どおりで、不具合ではなく、テストの穴。

## 修正

- `src/layout/shape_fit.test.ts`：「向きを問わない形（正方形に近い・縦長）」を追加（1件）。正方形に近い形と縦長について、流れる方向が上・右・下・左・なしのどれでも、同じ大きさには同じ判定を返すことを、境目を含む8通りの大きさで確かめる

## 確認

- 2つの変異（正方形に近い形・縦長が方向に左右される）が、追加したテストで検出されることを確かめた（それぞれ1件落ちる）。確かめたあとは元に戻した
- `bun run check`：終了コード0（UIのテスト528件・Rustのテスト114件）
